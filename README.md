# CarHelper

## Description 
CarHelper is a web app we are building to help car owners easily figure out what is wrong with their cars, understand those confusing dashboard warning lights, and get a clear idea of repair and resale prices.


## Features
- ***Image-Based Diagnosis:*** Users take a photo of a warning light, and the AI instantly identifies the problem.
- ***Repair Cost Estimation:*** Estimates repair prices for the Saudi market so users do not pay too much.
- ***Car Resale Valuation:*** Calculates a fair resale price based on the car's current shape.

# Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Database:** MySQL
- **Testing:** JUnit
- **AI Integration:** AI Package, API Adapter

## AI Usage

Ai tools were used to assist in specific parts of the **CarHelper** project. AI support was limited to selected code segments and was not used to develop the entire system.

The following areas involved AI assistance:

- **AI Package:** Assistance was used for implementing and refining certain functionalities within the ai package.
- **API Adapter:** AI was used for a small number of code lines in the ApiAdapter component to support API integration.
- **Frontend Development:** AI-assisted suggestions were used for some user interface elements and frontend code improvements.
- **Unit Testing:** AI was utilized to help generate and improve selected unit test cases.

All AI-generated content was reviewed, validated, and modified when necessary by the development team. Final design decisions, system architecture, implementation, integration, and testing remained under the responsibility of the project developers.
